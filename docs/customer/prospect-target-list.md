## How this list was built and its limits

Found via web search (`WebSearch`, US-indexed results, so non-US coverage is weaker than the
company names imply — treat Asia/EU rows as a starting point to verify, not a vetted set). Every
row cites the source URL actually returned by search. No transaction volume, data system, or
decision-maker was verified — that only happens on a real call (`docs/customer/data-acquisition-plan.md`
§4). Company size and "independent/family-owned" framing come from each company's own marketing
copy or a secondary listicle, not from any owned-data source; some entries cite a secondary article
rather than the company's own site because that's what named them — those are flagged. A few
larger, enterprise-shaped organizations turned up in the same searches (FCM Travel, ATPI, CTM,
Adecco, Moglix, IndiaMART, TradeAsia) and were deliberately excluded — they'd need procurement
cycles, not a founder-led data ask, matching the bad-signal list in
`docs/customer/data-acquisition-plan.md` §9.
